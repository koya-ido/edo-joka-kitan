## 1. プロジェクト概要

- **プロダクト名（仮）**:
  - `穢土浄化奇譚 〜 妖魔祓ひの旅路 〜`
- **一言説明（エレベーターピッチ）**:
  - 穢れに侵された土地を浄化する旅を続ける主人公が、自らの周囲に守護結界を展開し、迫り来る妖怪の群れを遠隔術で討ち払う、広告や課金制限のない和風縦型ローグライクタワーディフェンスWebゲーム。
- **ストーリーと世界観**:
  - **背景ストーリー**:
    - 各ステージは妖怪の怨念によって「穢れた土地」と化している。
    - 主人公（陰陽師・巫女等）は各地を巡る浄化の旅の途上、穢れた地に結界を展開して精神を研ぎ澄まし、押し寄せる妖怪の猛攻を退けながら「土地の浄化（ステージクリア）」を達成して次なる地へと旅を続けていく。
  - **世界観・防衛ビジュアル**:
    - 固定施設や建物の拠点を構えるのではなく、**画面下部中央に旅の主人公が一人凛と立ち、その周囲を神聖な守護結界（円形・半円のエフェクト）で覆っている**ビジュアル表現。
    - 妖怪はこの守護結界を破ろうと画面上部から殺到する。
  - **迎撃スタイル（遠隔術射出・9大武器ジャンル）**:
    - 刀剣（飛ぶ斬撃）、弓矢（直線貫通）、手裏剣（高連射・多重拡散）、鏡（持続光線レーザー）、呪符（誘導・状態異常爆発）、火縄銃（超高威力範囲爆発）、扇・軍配（突風ノックバック）、神具・鈴（全方位円形パルス）、霊珠・勾玉（結界周囲旋回削り）。
    - ※近接攻撃や自由移動はなく、すべて結界内の主人公から放つ遠隔・弾道・展開術。
- **目標・目指す成果（成功基準）**:
  - 1プレイ3〜5分程度の手軽さで、土地を浄化する爽快感、インゲームのスキルビルド、そして「水晶の勾玉」による育成や「翡翠」を用いた無料ガチャによるコレクションがシームレスに機能する完全クライアント完結型ゲームを実現する。

## 2. 背景と解決したい課題

- **現状の課題・ペインポイント**:
  - 市販のタワーディフェンスやサバイバー系ゲーム（「EDEN 最終防衛ライン」「セルサバイバー」等）は面白い一方で、強制動画広告の頻出、スタミナ回復待ち時間、過度な課金圧力が強く、自分のペースで純粋に没頭しにくい。
- **なぜ今このプロダクトを作るのか（開発動機）**:
  - 待ち時間や広告のストレスを一切排除し、大好きな和風・日本神話の世界観の中で、好きなだけ戦略の試行錯誤、育成、ガチャ周回を楽しめる自分専用の高品質なWebゲームを構築するため。

## 3. 想定ユーザーと利用シーン

- **メインターゲット（ペルソナ）**:
  - 開発者自身（個人利用・セルフホストまたは静的Web配信によるプレイ）。
- **主な利用シーン・導線**:
  - PCブラウザ（マウス操作）およびスマートフォンブラウザ（タッチ操作）からアクセスし、隙間時間にサクッとプレイ。
  - 毎日のログインボーナスや、1プレイ3〜5分のステージクリアで「水晶の勾玉」「翡翠」を獲得し、育成とガチャを回すサイクル。

## 4. コア機能要件

- **Must（初期リリース必須機能）**:
  - **和風防衛バトルシステム（結界展開と土地の浄化）**:
    - 画面下部中央に旅の主人公が立ち、その周囲に円形の守護結界を展開して、画面上部から進軍してくる妖怪ユニットを迎撃する縦型ディフェンス。
    - **完全自動索敵（オートエイム）＆自律発動**: 主人公の迎撃術は「最も結界に近い妖怪」を自動検知して射出。装備した最大3つの武器は、それぞれの攻撃頻度（クールダウン）完了に応じて自動でリズミカルに連射・発動する。
    - **倍速・一時停止機能**: 快適な周回のため、「一時停止（ポーズ）」および「等速 / 2倍速切り替え」機能をHUDに完備。
    - **ステージ・ウェーブ構成（全10ウェーブ・ボス戦）**: 1プレイ3〜5分。各ステージは全10ウェーブで構成され、第1〜9ウェーブの猛攻を耐え抜き、最終第10ウェーブに出現する大妖怪（中ボス）を討ち倒すことで「土地の浄化（ステージクリア）」を達成。結界耐久値（HP）が0になると失敗（ゲームオーバー）。
    - **v1初期収録ステージ（全3ステージ）**:
      - **第壱節：迷いの竹林**（入門ステージ・小型妖怪中心）
      - **第弐節：逢魔の古道**（中級ステージ・高速妖や中型鬼の混成）
      - **第参節：怨嗟の廃神社**（上級ステージ・耐久妖や大妖怪ボスが待ち受ける激戦地）
    - **敗北時（ゲームオーバー）の救済仕様**: 途中で結界が決壊した場合でも、**到達ウェーブ数に応じた少量の「水晶の勾玉」を持ち帰ることが可能**（挑戦が無駄にならず、育成を繰り返して再挑戦できるRPGループを確立）。
  - **キャラクターステータス体系**:
    - **HP（耐久値）**: 主人公が展開する守護結界の最大耐久力。
    - **ATK（攻撃力）**: 飛ぶ斬撃、手裏剣、矢などの基礎ダメージ量。
    - **LUK（会心発生率）**: クリティカルヒットの発生確率。
  - **スキル体系（2層構造）と武器装備枠**:
    - **キャラスキル（パッシブ）**: キャラクター固有の常時発動効果（例: 結界HPの自然回復、LUK補正、被ダメージ軽減など）。
    - **武器スキル（アクティブ・最大3枠）**: 装備武器に紐づく主軸の迎撃術・攻撃アクション。**バトルに持ち込める武器は最大3つまで**装備可能。
  - **全9大武器ジャンルの分類と弾道特性**:
    1. **弓矢系（例: 破魔弓、梓弓）**: 【長射程・直線貫通】画面最上部まで届く高速矢で縦一列の妖怪を射抜く。
    2. **刀剣系（例: 霊刀、銘刀・波紋）**: 【中射程・扇状薙ぎ払い】三日月型の飛ぶ斬撃波（真空刃）を放ち、横に並んだ妖怪を一掃。
    3. **手裏剣系（例: 風魔手裏剣、くない）**: 【高連射・多重拡散・滞留】扇状に多数の刃を乱射し、その場に留まり多段ヒット。
    4. **鏡系（例: 八咫鏡、神鏡）**: 【持続照射・光線反射】神聖な光線（レーザー）を放ち続け、妖怪や結界に反射して屈折照射。
    5. **呪符系（例: 式神符、雷公符）**: 【誘導・状態異常・時限爆発】妖怪を自動追尾して貼り付き、鈍足化や持続炎上後に炸裂。
    6. **火縄銃系（例: 種子島、大筒）**: 【超高火力・着弾範囲爆発】低連射だが、直撃時に広範囲の妖怪を爆風で吹き飛ばす重砲。
    7. **扇・軍配系（例: 天狗の団扇、風神軍配）**: 【突風・ノックバック（押し戻し）】激しい突風で迫る妖怪を結界から奥へ押し戻す遅延特化。
    8. **神具・鈴系（例: 神楽鈴、錫杖）**: 【全方位円形波動】清めの神聖パルスを全方位に放ち、結界間際まで群がった妖怪を全周迎撃。
    9. **霊珠・勾玉系（例: 八尺瓊勾玉、式神球）**: 【旋回オービット・接触削り】結界の周囲を高速旋回し、接近した妖怪を自動でガリガリ削る防衛輪。
  - **メタプログレッション（永続育成機能・加算方式）**:
    - 主人公ステータス（HP, ATK, LUK）の勾玉強化や、武器重複時の合成・精錬強化などの永続強化要素は、ゲームバランスを破綻させず着実な成長を実感できるよう**加算方式（Additive）**で算出する（例: Lvごとに固定値または基礎値に対する固定幅加算）。
  - **ゲーム内通貨と入手手段（2種に限定）**:
    - **水晶の勾玉（基本通貨）**: 主人公ステータス（HP, ATK, LUK）やスキルのレベルアップ、および**バトル中のインゲーム強化（3択スキル）の再抽選（リロール）**に使用。
    - **翡翠（ひすい・希少石）**: ガチャ専用アイテム（5個でガチャ1回実行）。
    - **入手手段（明確化）**:
      1. **ログインボーナス**: 毎日午前0:00（00:00）更新。日付変更後にアプリ起動で受け取り可能。
      2. **ステージクリア報酬**: 穢れた土地を浄化（ステージクリア）した際に獲得。
  - **ゲーム内ガチャ機能（インゲーム無料ガチャ）**:
    - **キャラガチャ（v1全3名）**:
      1. **見習い陰陽師（初期配布・バランス型）**: パッシブ「神気結界（結界HP自然回復）」。
      2. **白狐の巫女（ガチャ排出・会心＆幸運型）**: パッシブ「稲荷の加護（LUK補正・勾玉獲得率UP）」。
      3. **影縫いの忍び（ガチャ排出・速度＆手数型）**: パッシブ「疾風迅雷（全武器の攻撃頻度UP）」。
    - **武器ガチャ**: 9大武器ジャンルのアクティブ術具を獲得。
    - **召喚単位**: 「1回召喚（翡翠5個）」および「10回連続召喚（翡翠50個）」。
    - **演出スキップ機能**: タップで演出を即座にスキップし、素早く結果確認が可能。
    - **武器重複時の合成強化システム**: ガチャで既に所持している武器が重複して排出された場合、**「水晶の勾玉」を消費することなく合成（精錬/限界突破）**され、武器の基本攻撃力やアクティブスキルの性能が直接強化される。
    - **キャラ重複時の覚醒（凸強化）システム**: ガチャで既に所持しているキャラクターが重複して排出された場合、自動的に**覚醒（凸強化）**が行われ、基礎HP/ATK/LUKの補正値やパッシブスキル効果が一段階強化される。
  - **新規開始時の初期配布**:
    - 初回起動時（初期セーブデータ作成時）に、初期主人公「見習い陰陽師」、初期武器「銘刀・波紋（飛ぶ斬撃）」、初ガチャ用の翡翠5個、および初期ステータス強化用の少量の水晶の勾玉をあらかじめ付与。
  - **インゲーム強化（ローグライク3択抽選＆再抽選）**:
    - 妖怪撃破で霊力（経験値）を獲得し、バトル中にレベルアップするたびに、以下の**3系統**からランダムに**3つの選択肢**が提示される。
      1. **基本ステータス強化（全体共通・全3種）**:
         - **攻撃力（ATK%）**: 全攻撃手段の基礎攻撃力の割合上昇。
         - **会心発生率（会心率%）**: クリティカルヒット確率の上昇。
         - **会心強化率（会心ダメージ倍率%）**: クリティカル発生時の与ダメージ倍率の上昇。
         - ※割合強化バフは、加算式ではなく**複利式（乗算方式）**を採用（例: 基礎100に50%強化を2回適用した場合、加算の200ではなく `100 × 1.5 × 1.5 = 225`）。特化ビルドを組むほど指数関数的に威力がインフレする。
      2. **武器ステータス強化（武器個別・全3種）**:
         - **攻撃頻度**: 該当武器の攻撃間隔短縮（発動クールダウン短縮）。
         - **武器攻撃力**: 該当武器固有の威力の割合上昇。
         - **有効時間**: 該当武器の弾道・斬撃波・術エフェクトの持続時間/残留時間の延長（長射程化や多重ヒット性の向上）。
      3. **武器スキルの開放**:
         - 編成画面で装備した最大3つの武器に紐づくアクティブ術（飛ぶ斬撃、破魔矢、手裏剣等）のアンロック・追加発動。
    - **再抽選（リロール）機能**: 所持している「水晶の勾玉」を一定数消費することで、提示された3択候補を再抽選して引き直すことが可能。
  - **ローカルセーブ・ロード機能**:
    - IndexedDB を利用し、所持通貨（水晶の勾玉・翡翠）、獲得済みキャラ・武器、ステータス強化度、ログインボーナス最終受取日を完全自動保存・復元。
  - **主要6大画面の構成**:
    1. **トップ画面（ホーム）**: ゲーム開始、所持通貨表示、ログインボーナス受取・確認モーダル（起動時の自動表示および、モーダルを閉じた後もいつでも再確認できる専用ボタンを常設）、デバッグ・検証用「セーブデータ初期化（IndexedDBリセット）ボタン」、各画面へのナビゲーション。
    2. **ステージ選択画面**: 穢れた土地（ステージ一覧）の選択・進行度確認、出撃導線。
    3. **ゲーム画面（バトル）**: Canvas戦闘描画（結界・妖怪・飛ぶ斬撃）、HUD、インゲーム3択スキルモーダル（勾玉リロール対応）、リザルトモーダル。
    4. **ガチャ画面**: キャラガチャ／武器ガチャのタブ切り替え、翡翠5個消費召喚、排出演出。
    5. **強化画面（社・育成）**: 水晶の勾玉を消費した主人公ステータス（HP, ATK, LUK）およびスキルの恒久強化。
    6. **編成画面**: 出撃する主人公1名（パッシブスキル）と**装備武器（最大3スロット）**の選択・装備、総合ステータスプレビュー。
  - **PC/スマホ両対応のレスポンシブCanvas UI**:
    - 画面サイズに応じた自動スケーリングと、タッチ/マウスクリックに最適化された操作系。
  - **疎結合なレンダラー・オーディオ設計**:
    - v1はCanvas 2D幾何学図形・パーティクル（回転手裏剣、狐火光球、三日月斬撃波など）で描画。
    - 将来的な和風スプライト画像やアニメーション、和楽器BGM/SEへの差し替えが容易なインターフェース設計。v1は無音で動作。
- **Nice-to-have（将来検討・優先度低）**:
  - **複数チャプター・ステージ展開**:
    - 「壱の鳥居（森林）」「逢魔が時（参道）」「幽世の深淵（本殿奥）」など、データ駆動でマップ背景や妖怪構成を拡張可能にし、順次ステージを選択して浄化していく進行マップ。
  - **和風スプライト画像・テクスチャ素材への差し替え**:
    - 幾何学図形からオリジナルの和風キャラクター・妖怪スプライトや美麗なエフェクト画像へのアップグレード。
  - **和風サウンド（SE / BGM）の実装**:
    - 和太鼓・篠笛・三味線を取り入れたBGMや、斬撃音・投擲音・爆発エフェクト音などの追加。
  - **ボス妖怪ウェーブ・特殊ギミック**:
    - 各穢れた土地の最深部で待ち構える大妖怪（酒呑童子、九尾の狐等）とのボスバトル。
- **扱う主要データ・エンティティのイメージ**:
  - **プレイヤー永続データ**: 所持「水晶の勾玉」、所持「翡翠」、各ステータス強化レベル（HP, ATK, LUK）、所持キャラクター一覧（キャラID、覚醒レベル）、所持武器一覧（武器ID、合成・精錬強化レベル）、装備中キャラID、装備中武器IDリスト（最大3枠）、ログインボーナス最終受取タイムスタンプ。
  - **キャラクター定義**: キャラID、名前、基礎HP/ATK/LUK補正、キャラスキル（パッシブ効果）。
  - **武器定義**: 武器ID、名前、武器ジャンル（弓矢/刀剣/手裏剣/鏡/呪符/火縄銃/扇・軍配/神具・鈴/霊珠・勾玉）、武器スキル（アクティブ術・弾道挙動パラメータ）。
  - **ラン内ステータス**: 現在ウェーブ、結界現在HP、習得済み一時スキル一覧、現在霊力/レベル。
  - **ステージ/ウェーブ定義**: ステージID、穢れ度、出現妖怪パターン、ウェーブ数、クリア報酬（勾玉、翡翠）。

## 5. 非機能要件・運用制約

- **想定ユーザー規模・アクセス頻度**:
  - 個人利用（シングルプレイヤー、クライアント完結）。
- **セキュリティ・認可要件**:
  - 外部サーバー通信やユーザー認証は一切不要。
  - 完全クライアントサイドで動作し、オフライン環境でもプレイ可能。
- **対応デバイス / ブラウザ環境**:
  - PCブラウザ（Google Chrome, Safari, Firefox 最新版）。
  - スマートフォンブラウザ（iOS Safari, Android Chrome 最新版）。
  - 60fps維持を目標とする軽量設計。
- **インフラ・コスト制約**:
  - サーバーレス・静的Webホスティング（GitHub Pages, Cloudflare Pages, Vercel 等）の無料枠で完全運用（ランニングコスト0円）。

## 6. 対象外事項 (Out of Scope)

- **ユーザー認証・アカウント管理・セッション管理**:
  - 会員登録、ログイン、ソーシャルログイン等は一切作成しない。
- **外部データベース・バックエンドAPI**:
  - サーバーサイドのデータ保存やAPI構築は行わず、IndexedDB のみで完結させる。
- **有償課金・スタミナ・外部広告システム**:
  - 現金決済、有償通貨、スタミナ回復待ち、動画リワード広告、バナー広告等は一切実装しない（ゲーム内のガチャは完全無料・インゲームアイテム「翡翠」のみ）。
- **オンラインマルチプレイ・ランキング・共有**:
  - 他プレイヤーとのリアルタイム対戦・協力や、オンラインランキングは含まない。
- **近接直接攻撃・キャラクターの移動操作**:
  - キャラクターを自由に歩き回らせて敵に直接近接攻撃を当てる操作は実装せず、固定拠点（結界）から前方へ弾道・飛ぶ斬撃・術を放つディフェンス形式に統一する。
- **v1における外部画像アセット読み込み**:
  - 初期バージョンでは外部画像ファイルのプリロードや複雑なスプライトシート描画は行わず、Canvas 2D幾何学図形（回転する手裏剣十字、狐火パーティクル、円弧斬撃線など）で完結させる。
- **v1におけるBGM・効果音（SE）の再生**:
  - 初期バージョンは無音でゲームプレイを完成させ、音源ファイルのロードや再生は行わない。
- **v1における複数チャプター選択UI**:
  - データ定義上は複数ステージに対応可能な構造にしておくが、v1では単一の連続防衛ステージ（無限/高難易度ウェーブ）のみを提供する。

## 7. 技術選定の希望・前提条件

- **希望する言語・フレームワーク**:
  - TypeScript, Vite, HTML5 Canvas API (2D Context)。
- **希望するDB・ストレージ**:
  - IndexedDB (扱いやすさのため `idb` などの軽量ラッパー利用を推奨)。
- **アーキテクチャ方針**:
  - **UI・描画分離（DOMオーバーレイ方式）**: 実験的な HTML-in-Canvas はブラウザ互換性（特に iOS Safari 非対応）の観点から採用を見送り、ゲーム戦闘描画層（Canvas 2D）の上に UI層（HTML/CSS）を重ねる堅牢な DOM オーバーレイ構成を採用する（PC・iOS・Android 全環境で安定動作を保証）。
  - レンダラー層（プロシージャル図形描画 ↔ 和風スプライト画像描画）とゲームロジック層を明確に分離し、後からのアセット差し替えを容易にする。
  - スキル体系（キャラスキル: パッシブ / 武器スキル: アクティブ）をデータ駆動で管理し、キャラ・武器の付け替えに応じたステータス計算を分離する。
  - ログインボーナス判定（0:00更新）を日付境界ロジックとして独立モジュール化する。
  - オーディオマネージャーもインターフェース化しておき、初期はNo-op実装とする。
  - ステージ定義・スキル定義・妖怪定義をデータ駆動（マスタ設定オブジェクト）とし、チャプター追加や敵バリエーション拡張をコード修正なしで可能にする。
- **確定技術スタック（確定事項）**:
  - **言語**: TypeScript（strictモード）
  - **フロントエンドFW・ビルド**: React + Vite
  - **バックエンドFW**: なし（完全クライアント完結・静的Webホスティング）
  - **描画エンジン**: HTML5 Canvas API (2D Context)（`useRef` 等でReactの再描画サイクルから分離し、60fpsを維持）
  - **DB / ストレージ**: IndexedDB + `idb`（軽量Promiseラッパーによる型安全なローカルセーブ管理）
  - **認証基盤**: なし（Out of Scope：個人利用・外部通信なしのため不要）
  - **UIライブラリ方針**: Tailwind CSS ＋ カスタム和風コンポーネント（汎用UIキット不使用。アイコンは軽量SVG / Lucide等を利用）
  - **状態管理方針**: React標準（Context / Hooks）または軽量ストア（`zustand` 等）を用い、CanvasゲームループとHUD・モーダル間の同期を疎結合に分離

## 8. 検討中事項・メモ

- **決定済み事項メモ**:
  - **迎撃エイム**: 「最も結界に迫っている妖怪」を自動検知して射出する完全オートエイムを採用。
  - **バトル進行＆快適機能**: 各ステージはウェーブ進行型。倍速（等速/2倍速）および一時停止（ポーズ）機能をHUDに常設。
  - **敗北時の仕様**: 結界決壊時でも到達ウェーブ数に応じた少量の「水晶の勾玉」を持ち帰れる安心設計。
  - **ガチャシステム**: 1回召喚（翡翠5個）および10回連続召喚（翡翠50個）、演出タップスキップ対応。
  - **初期データ**: 見習い陰陽師、銘刀・波紋、初期翡翠5個（初ガチャ用）を初期配布。
